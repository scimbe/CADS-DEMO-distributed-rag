Distributed RAG

Ask a question about a small real library — Sherlock Holmes and Pride and Prejudice — and get an answer that cites exactly which retrieved passage backed each claim. The service also recalls related past questions from its own memory of prior interactions.

Why this is not just a chatbot

Grounded, on purpose

How this works

The corpus behind this demo is real public-domain text — ingested from Project Gutenberg, Open Library and the Internet Archive — not synthetic or model-generated text. Every question is embedded locally and matched against that corpus to retrieve the most relevant passages, which are numbered [1], [2], etc.

The model is then instructed, at the system-prompt level, to answer only using facts explicitly stated in those retrieved passages, and to cite the passage number after every claim. It is told to say so plainly, rather than guess, if the passages don't cover part of the question. A plain chatbot will happily answer from its training data whether or not it actually knows; this one is structurally blocked from doing that — if a fact isn't in the passages shown on this page, it isn't allowed to appear in the answer.
